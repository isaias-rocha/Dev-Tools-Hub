# 🧰 Dev Tools Hub

Repositório dedicado a reunir **ferramentas essenciais** que facilitam o desenvolvimento de software, desde design até produtividade no dia a dia.

A ideia é centralizar recursos úteis que ajudam desenvolvedores a economizar tempo, manter padrão visual e melhorar a qualidade dos projetos.

---

## 🎯 Objetivo

Organizar e compartilhar ferramentas que auxiliam em:

* 🎨 Design e escolha de cores
* 🖼️ Imagens sem direitos autorais
* ⚙️ Produtividade no desenvolvimento
* 💡 Inspiração para interfaces
* 🧪 Testes e validações

---

## 🎨 Design & Cores

Ferramentas para criar paletas, ícones e manter consistência visual:

* [Coolors](https://coolors.co/) → Geração automática de paletas de cores modernas.
* [Color Hunt](https://colorhunt.co/) → Coleção de combinações de cores prontas e populares.
* [ColourLovers](https://www.colourlovers.com/) → Comunidade para compartilhamento e criação de paletas.
* [Khroma](https://khroma.co/) → Ferramenta de IA que aprende suas cores favoritas para gerar paletas ideais.
* [Lucide Icons](https://lucide.dev/) → Biblioteca de ícones open-source, consistentes e fáceis de customizar.
* [Svgl](https://svgl.app/) → Excelente biblioteca de logos de marcas e tecnologias em formato SVG.

---

## 🖼️ Imagens Gratuitas (Sem direitos autorais)

Bancos de mídia perfeitos para layouts, aplicativos, sites e protótipos:

* [Unsplash](https://unsplash.com/) → Imagens de alta resolução e com olhar fotográfico artístico.
* [Pexels](https://www.pexels.com/) → Grande variedade de fotos e vídeos gratuitos para uso comercial.
* [Pixabay](https://pixabay.com/) → Amplo catálogo de fotos, ilustrações e vetores gratuitos.

---

## 🧠 Inspiração de UI/UX & Componentes

Ótimos portfólios e comunidades para buscar ideias de layouts modernos:

* [Dribbble](https://dribbble.com/) → Vitrine global de design de interfaces e conceitos visuais.
* [Behance](https://www.behance.net/) → Plataforma da Adobe para portfólios completos de design e UX.
* [Mobbin](https://mobbin.com/) → Biblioteca real de capturas de tela de aplicativos mobile populares.
* [Uiverse](https://uiverse.io/) → Elementos de UI (botões, cards, inputs) criados pela comunidade com CSS ou Tailwind.

---

## ⚙️ Ferramentas Visuais Úteis

* [Google Fonts](https://fonts.google.com/) → O maior catálogo de fontes tipográficas gratuitas e prontas para a web.
* [Icons8](https://icons8.com/) → Coleção massiva de ícones, ilustrações, fotos e músicas de fundo.
* [Remove.bg](https://www.remove.bg/) → Remoção automática do fundo de qualquer imagem em poucos segundos através de IA.

---

## 🚀 Produtividade & Código

* [Regex101](https://regex101.com/) → Ambiente interativo para criar, testar e debugar expressões regulares.
* [JSON Formatter](https://jsonformatter.org/) → Formatador, validador e conversor de estruturas JSON.
* [CodePen](https://codepen.io/) → Ambiente de desenvolvimento social para testar códigos front-end (HTML, CSS, JS) rapidamente.
* [Carbon](https://carbon.now.sh/) → Cria e customiza imagens lindas de trechos de código para compartilhamento.
* [Transform tools](https://transform.tools/) → Conversor universal de código (ex: JSON para TypeScript, HTML para JSX).
* [TLDR Pages](https://tldr.sh/) → Versão simplificada e prática dos manuais do terminal (`man`), focada em exemplos diretos.

---

## 🧪 Testes, APIs & Performance

* [Hoppscotch](https://hoppscotch.io/) → Alternativa open-source, leve e baseada no navegador ao Postman para testar APIs.
* [Httpbin](https://httpbin.org/) → Um serviço simples para testar e inspecionar diferentes tipos de requisições HTTP.
* [PageSpeed Insights](https://pagespeed.web.dev/) → Ferramenta do Google para medir performance, acessibilidade e práticas de SEO de sites.

---

## ✨ Animações & Efeitos CSS

* [Animista](https://animista.net/) → Coleção de animações CSS prontas com interface visual para customizar e copiar o código.
* [CSS Glassmorphism](https://cssglass.io/) → Gerador visual para criar o efeito de "vidro fosco" moderno usando propriedades CSS.
* [LottieFiles](https://lottiefiles.com/pt/) → Projetado para criar animações ultra-leves, altamente personalizáveis e interativas para web, aplicativos...

---

## 🗂️ Git, Documentação & Arquitetura

* [Excalidraw](https://excalidraw.com/) → Quadro branco virtual com estilo de desenho manual, perfeito para diagramar arquiteturas de software.
* [GitIgnore.io](https://www.toptal.com/developers/gitignore) → Criação rápida e automática de arquivos `.gitignore` customizados para as tecnologias do seu projeto.
* [readme.so](https://readme.so/) → Editor interativo modular que facilita muito a montagem inicial de um arquivo README.

---

## 💾 Banco de Dados & Mock de Dados

* [Mockaroo](https://www.mockaroo.com/) → Gerador de dados fictícios realista (nomes, e-mails, IPs) em formatos como CSV, JSON e SQL para testes.
* [dbdiagram.io](https://dbdiagram.io/) → Ferramenta gratuita para desenhar diagramas de relacionamento de banco de dados (DER) usando apenas código.

---

## 🌐 Deploy & Hospedagem Gratuita

* [Vercel](https://vercel.com/) → A melhor plataforma para hospedagem e deploy automatizado de aplicações front-end e estáticas.
* [Netlify](https://www.netlify.com/) → Excelente plataforma de deploy com suporte a CI/CD contínuo acoplado ao GitHub.
* [Render](https://render.com/) → Ótima opção gratuita para hospedar pequenos servidores web (Node.js, Python, Go) e bancos de dados.
