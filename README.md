# 🧰 Dev Tools Hub

Repositório dedicado a reunir **ferramentas essenciais** que facilitam o desenvolvimento de software, desde design até produtividade no dia a dia.

A ideia é centralizar recursos úteis que ajudam desenvolvedores a economizar tempo, manter padrão visual e melhorar a qualidade dos projetos.

---

## 🎯 Objetivo

Organizar e compartilhar ferramentas que auxiliam em:

* 🎨 Design e escolha de cores
* 🖼️ Imagens sem direitos autorais
* ⚙️ Produtividade no desenvolvimento
* 💡 Inspiração para interfaces
* 🧪 Testes e validações

---

## 🎨 Design & Cores

Ferramentas para criar paletas e manter consistência visual:

* https://www.colourlovers.com/ → criação de paletas de cores
* https://coolors.co/ → geração automática de paletas
* https://colorhunt.co/ → combinações modernas e prontas
